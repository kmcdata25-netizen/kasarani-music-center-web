# Kasarani Music Center — Official Website & Student Portal

This repository hosts the official landing page and student portal for **Kasarani Music Center**, Nairobi.

## Features
- **Modern Responsive Design**: Optimized for mobile, tablet, and desktop.
- **Direct Student App Downloads**: Download links for the Android APK with installation guidance.
- **Dynamic Version Synchronization**: Automatically syncs the latest published APK version from GitHub Releases.
- **Continuous Deployment**: Connected to Netlify for automatic build and deployment on every push to `main`.

## Local Development
Open `index.html` in any modern web browser, or run a local server:
```bash
npx serve .
```

## Production Deployment
Configured for automatic deployment on [Netlify](https://www.netlify.com).
- **Publish directory**: `.`
- **Build command**: None (Static)
